# eBay 2026 University Machine Learning Competition – Canada

## Project Overview
This repository is configured for the **eBay 2026 University Machine Learning Competition – Canada**.

### Task Description
The task involves **German automotive NLP / NER / structured aspect extraction**.

### Important Guidelines & Rules
- **Data Privacy**: Competition data is strictly restricted and must **never** be committed to version control or uploaded to any external service. All data processing and modeling stay strictly local on this machine.
- **Local Tooling**: The project will utilize local Python ML tooling.
- **Workflow Strategy**: Model training will not start until the dataset schema and validation strategy are thoroughly understood.
